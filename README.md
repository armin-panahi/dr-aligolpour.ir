# Dr. Ali Golpour — Beauty Clinic Website

A modern, responsive, and professional website developed for **Dr. Ali Golpour Beauty Clinic**.

The project is designed to provide a clean and elegant online presence for the clinic while delivering a smooth and user-friendly experience across desktop, tablet, and mobile devices.

## 🌐 Live Website

**https://dr-aligolpour.ir**

---

## ✨ Features

* Modern and elegant user interface
* Fully responsive design
* Mobile-first layout
* RTL support for Persian content
* Persian-language user interface
* Clean and structured HTML markup
* Interactive elements powered by JavaScript
* Smooth navigation and user interactions
* Optimized layout for different screen sizes
* SEO-friendly structure
* Custom visual identity designed for the clinic
* Fast and lightweight front-end architecture

## 🚀 Getting Started

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/armin-panahi/dr-aligolpour.ir.git
```

### 2. Navigate to the project directory

```bash
cd dr-aligolpour.ir
```

### 3. Run the project

Open `index.html` directly in your browser, or use a local development server such as **VS Code Live Server**.
