# وب‌سایت تک‌صفحه‌ای «جراحی و زیبایی گل پور»

نسخه استاتیک آماده شروع توسعه با HTML + CSS + JavaScript.

## فایل‌ها
- index.html — ساختار کامل صفحه و SEO پایه
- style.css — طراحی کاملاً ریسپانسیو، شیشه‌ای و مشکی/کرم
- script.js — Canvas متحرک، انیمیشن ورود، منوی موبایل و فرم نمایشی

## ساختار بصری
این پروژه از الگوی کلی سایت مرجع Alfredo Hoyos الهام گرفته: معرفی برند/پزشک، رویکرد، خدمات، مسیر مراجعه و دعوت به ارزیابی/نوبت. اما معماری صفحه، چیدمان، فرم کارت‌ها، Hero و زبان بصری برای گل پور به‌صورت مستقل طراحی شده است.

## جایگزینی اطلاعات
مواردی که با «—»، «IMAGE» یا «نمونه» مشخص شده‌اند با اطلاعات واقعی کلینیک جایگزین شوند:
- نام پزشک و تیم
- آدرس و شماره تماس
- خدمات واقعی
- تصاویر واقعی کلینیک و خدمات
- مجوزها و سوابق
- متن‌های FAQ
- روش واقعی دریافت درخواست نوبت

## اتصال فرم
فرم فعلاً Front-end است. برای استفاده واقعی می‌توان آن را به WordPress/PHP، Formspree، Email API، WhatsApp یا CRM متصل کرد.

## نکته پزشکی
از درج ادعاهای قطعی درباره نتیجه درمان، تضمین نتیجه یا اطلاعات پزشکی تاییدنشده خودداری کنید. متن نهایی باید توسط کلینیک و متخصص مربوطه تأیید شود.


## تغییرات نسخه جدید
- منوی اصلی: خانه، درباره من، خدمات، تخصص، مسیر، تماس با ما + رزرو نوبت
- تصویر بزرگ در Hero بالای صفحه
- تصویر بزرگ دوم در بخش تخصص در میانه صفحه
- بخش اختصاصی «قبل و بعد» با دو نمونه قابل جایگزینی
- حفظ تم مشکی/کرم، Glassmorphism و Canvas
